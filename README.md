# 💻 Estudos em Linguagem C

Bem-vindo ao meu repositório de estudos em **Linguagem C**!

Este repositório reúne exercícios e implementações desenvolvidos durante minha formação em **Análise e Desenvolvimento de Sistemas**.

O objetivo é desenvolver meus conhecimentos em lógica de programação, algoritmos, gerenciamento de memória e estruturas de dados.

## 📁 Organização do Repositório

### 📘 Fundamentos

Exercícios introdutórios de programação em C.

**Conteúdo:**
- Calculadora
- Fatorial
- Cálculo de IMC
- Conversão de números
- Verificações condicionais
- Identificação de números primos

### 🌳 Estruturas de Dados

Implementações de estruturas utilizadas na organização e manipulação de informações.

| Estrutura | Conceito |
|---|---|
| Árvore Binária | Organização hierárquica de dados |
| Fila Circular | Estrutura FIFO com organização circular |
| Fila Encadeada | Filas utilizando ponteiros |
| Lista Duplamente Encadeada | Navegação entre nós |
| Pilha | Estrutura LIFO |
| Pilha Duplamente Encadeada | Manipulação de nós e ponteiros |

Também estão incluídos exercícios envolvendo listas e manipulação de elementos.

### ⚙️ Algoritmos

**Heap Sort:** implementação de um algoritmo de ordenação baseado em heap.

### 🧩 Mini Projetos

**Inclusão de Cliente:** exercício de cadastro e manipulação de informações.

## ▶️ Como Executar

Para compilar os arquivos, é necessário possuir um compilador C, como o **GCC**.

**1.** Clone este repositório:

```bash
git clone https://github.com/Jabu-BG/Codigos-em-C.git
```

**2.** Acesse a pasta:

```bash
cd Codigos-em-C
```

**3.** Compile um exercício:

```bash
gcc fundamentos/fatorial.c -o fatorial
```

**4.** Execute o programa:

No Linux/macOS:

```bash
./fatorial
```

No Windows (PowerShell):

```powershell
.\fatorial.exe
```
